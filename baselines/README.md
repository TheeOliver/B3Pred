# External model implementations

Each directory contains the local source used or inspected for a comparison model, with upstream READMEs and available license notices retained. These models do not share one Python environment or identical training interfaces. The repository's root MIT license applies only to project-authored code; it does not relicense third-party source or model weights. The checked-out Atom-Attention-MPNN, RGCN, BBB uncertainty project, and DeePred-BBB snapshots have no license file in the local repository histories. Confirm redistribution terms with those projects before publishing their copied source. Use the parent [`docs/reproducibility.md`](../docs/reproducibility.md) as the common protocol and keep each model's generated files in its own output directory.

## Atom-Attention-MPNN

The source is in `atom_attention_mpnn/`; the upstream `chemprop` package is included. With the model's dependencies installed, a B3DB train/validation/test run follows the original CLI:

```bash
python baselines/atom_attention_mpnn/train.py \
  --data_path data/b3db_tanimoto_train.csv \
  --smiles_column SMILES --target_columns target \
  --separate_val_path data/b3db_tanimoto_val.csv \
  --separate_test_path data/b3db_tanimoto_test.csv \
  --atom_attention --normalize_matrices \
  --features_generator morgan_count --no_features_scaling \
  --metric auc --extra_metrics accuracy precision recall specificity \
  --epochs 30 --batch_size 50 --ensemble_size 5 --seed 42 \
  --save_dir experiments/atom_attention_seed42
```

GPU is recommended. The paper's three-seed protocol uses distinct seeds and output directories. Save the command and `args.json` generated by Chemprop alongside the scores.

## RGCN

`rgcn/` contains the RGCN source plus the B3DB adapter `run_rgcn_external.py`. The upstream README explains how to fetch the protein/drug graph resources; those large external assets are not included. For the adapter's current options, run:

```bash
python baselines/rgcn/run_rgcn_external.py --help
```

Supply the fixed train/test CSVs and output path, and use `data/prepared/sdata_prepared.csv` for LCD evaluation. Record which upstream graph resource files were used.

## Classical Mordred descriptors

`classical_ml_descriptors/run_bbm.py` computes Mordred 2D descriptors and trains RFC, Gradient Boosting, and Logistic Regression. It reports all three and writes the RFC result separately:

```bash
python -m pip install mordred
python baselines/classical_ml_descriptors/run_bbm.py \
  --train data/b3db_tanimoto_train.csv \
  --test data/b3db_tanimoto_test.csv \
  --out experiments/classical_mordred_seed42 --seed 42
```

The script's input accepts `SMILES`/`target` and common aliases. It uses only its `--train` file for fitting; to match the paper protocol, the validation split should be combined with train before running this standalone script, or use the exact prepared train file used in the original experiment. Do not compare this result directly to the in-house `classical_ml.py` without disclosing the descriptor/feature difference.

## VAE-Embeddings

`vae_embeddings/run_vae_bbb.py` supports `MLP`, `LR`, or `ResNet`, with Morgan fingerprints or a PVAE checkpoint. The paper's tested path was Morgan fingerprints because a pretrained VAE checkpoint was not available:

```bash
python baselines/vae_embeddings/run_vae_bbb.py \
  --train data/b3db_tanimoto_train.csv \
  --test data/b3db_tanimoto_test.csv \
  --out experiments/vae_fingerprint_seed42 \
  --model MLP --feature fingerprint --seed 42
```

This wrapper trains on the supplied train file; use the same train/validation handling as the recorded study if comparing metrics.

## DeePred-BBB

`deepred_bbb/` includes the published inference script, its checkpoint, PaDEL-Descriptor, and PaDEL notices. It makes fixed-checkpoint predictions rather than training a model. Follow its README and provide an input SMILES file. Its outputs are not interchangeable with the train/validation CLI's metric JSON without computing metrics against the corresponding labels.

## AttentiveFP and GROVER-BBBp

Source modules and training/evaluation scripts are under `bbb_uncertainty_project/`. That upstream project expects prepared feature files and has a model-specific command line; see its retained README. The pretrained weights used for the paper's reported fixed-checkpoint inference are not included in this repository.

## ChemBERTa-FT and MolCLR

The experiment scripts are in `chemberta_molclr/`. They load pretrained model code/assets and are GPU/memory intensive. Inspect the configuration section at the top of each script, set its data/output environment variables for this checkout, and retain the model identifier/revision, tokenizer, dependency lock, and run JSON. Their separate protocols are not exposed through `experiments.py`.

## Models without local source

LightBBB and Deep-B3 were evaluated through public interfaces. Their local code was not present in the project, and those numbers cannot be regenerated from this checkout. See the reproduction table for provenance.
