# Manuscript source

`main.tex` and `references.bib` are copied from the study workspace. The figures present in the workspace are included here. The manuscript currently references additional absent assets: `prisma.png`, `panel_A_descriptors.png`, `panel_B_scaffold.png`, `panel_C_tsne.png`, `fig6_hpo_bar.png`, and `fig_gin_embeddings.png`. Consequently, a full PDF cannot be rebuilt from this folder alone until those source figures are restored or regenerated from their original data. `generate_figures.py` produces only the figures documented in that script; it does not generate every image referenced by the manuscript.

The paper is included for provenance and to make the evaluated model list and reported metrics discoverable. See the repository's reproducibility guide for which values can be regenerated from code and data in this repository.
